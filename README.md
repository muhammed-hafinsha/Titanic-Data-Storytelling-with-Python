# Titanic Data Storytelling with Python

## Project Overview
This project explores the famous Titanic dataset using Python for data cleaning, preprocessing, exploratory data analysis (EDA), and data visualization. The objective is to uncover patterns and factors that influenced passenger survival during the Titanic disaster.

## Dataset
The dataset contains passenger information such as:
- Survival Status
- Passenger Class (Pclass)
- Gender
- Age
- Fare
- Embarkation Port

## Analysis Performed

### Data Preprocessing
- Removed unnecessary columns
- Handled missing values
- Checked and treated outliers
- Performed feature engineering
- Prepared data for analysis

### Univariate Analysis
- Survival distribution
- Gender distribution
- Age distribution
- Passenger class distribution
- Fare distribution

### Bivariate Analysis
- Gender vs Survival
- Age vs Survival
- Passenger Class vs Survival
- Fare vs Survival

### Multivariate Analysis
- Correlation heatmap
- Relationships among multiple variables
- Survival trends across different passenger groups

## Key Findings
- More passengers died than survived.
- Female passengers had a significantly higher survival rate than male passengers.
- First-class passengers showed better survival chances compared to lower classes.
- Most passengers were between 20 and 40 years old.
- Fare and passenger class had a noticeable relationship with survival outcomes.
